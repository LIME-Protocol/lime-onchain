# SDK Lives in lime-sdk Repository

The official LIME Solana SDK lives in `LIME-Protocol/lime-sdk` and is published as `@lime/solana`. The `lime-onchain` repository should focus on Programs, protocol tests, IDLs, Program ID documentation, and audit-ready on-chain artifacts; any SDK code that remains here is temporary or legacy until extracted. Reference Frontend and Order Book systems are integration examples for Market Operators rather than the primary product surface.
